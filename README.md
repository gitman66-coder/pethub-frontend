# PetHub (Angular)

EWP project - Unit V Angular. A pet shop frontend (dogs, cats, rabbits, reptiles, about, checkout & delivery).

## How to run
```
npm install
ng serve
```
Then open http://localhost:4200

(if `ng` is not found use `npx ng serve`)

## Folders
- src/app/header, home, pet-list, about, checkout, not-found -> components
- src/app/services -> pet.service, cart.service, order.service
- public/pets.json, public/cities.json -> data loaded with HttpClient
